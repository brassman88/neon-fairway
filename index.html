NOTES

  • Local testing = no pid in the link. The games then use the whole-game segment (tp-all / course-all), debug is on, and every record is marked test: true.
  • Study mode = a pid in the link (as Qualtrics will send). Researcher tools and test shortcuts are hidden unless debug=1.
  • course.html (V21) reads these settings: it plays only the chosen section, takes the bag from the link (no seed card with a pid) and shows an error card for a bad bag or segment. target.html plays tp-practice (ends at "Clubs chosen") or tp-rounds (bag and labels from bag and letters); with no segment it plays the whole game (tp-all). course.html logs shot, hole and segment records (with debug: Download data in the researcher panel). target.html (v41) logs shot, estimate, club summary, bag choice, prediction, round and segment records (with debug: Download data above the game). cond=fb-hidden hides every running and round total in the scored rounds; fb-visible or no cond shows them.
  • Open these pages from a web server (GitHub Pages, or python3 -m http.server), not by double-clicking the file.
